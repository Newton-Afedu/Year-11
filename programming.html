Extra practice: file handling

After completing the programming unit, practise opening, reading, writing and closing text files. This extension comes from the supplied teaching guidance and is separate from the 8.1–8.2 objectives shown.

with open("results.txt", "w") as file:
    file.write("Alex,75\n")

with open("results.txt", "r") as file:
    print(file.read())
